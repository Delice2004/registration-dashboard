 Student Event Registration Dashboard

A responsive web application for managing student events with registration, cancellation, search functionality, and dark mode support. Built using HTML, Tailwind CSS, JavaScript, and LocalStorage.

 Features

. View available events with details including title, category, seats, and registrations  
. Add new events dynamically through a form  
. Register for events with seat validation  
. Cancel event registration  
. Search events by title or category in real time  
. Display live statistics including total events, registered students, and remaining seats  
. Toggle between light and dark mode  
. Persistent data storage using LocalStorage  

 Technologies Used

. LocalStorage API

 How It Works

. Events are stored in a JavaScript array  
. Data is saved in browser LocalStorage for persistence  
. DOM is updated dynamically using JavaScript  
. Array methods like filter and reduce are used for search and statistics  
. UI updates automatically after each action  



 Functionalities

. Add event with title, category, and seats  
. Register users to events with seat limit check  
. Cancel registration and update available seats  
. Search events instantly without page reload  
. Update statistics in real time  
. Switch theme using dark mode toggle
